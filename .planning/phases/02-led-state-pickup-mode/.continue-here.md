## 02-03 Task 2 — hardware verification + bug fixes (commit adbf45c)
Hardware tested against Logic Pro. Three bugs found and fixed:

**Fader pickup false re-entry:**
- setDawValue() was comparing incoming echo against _dawValue14bit (previous DAW value).
  Logic's echo delta = distance fader moved → any move > 3% triggered OUT_OF_SYNC.
- Fix: compare against _lastFader14bit (physical position). Echo ≈ physical → no trigger.
  Real bank switch (far from physical) → triggers correctly.
- BANK_SWITCH_THRESHOLD raised 512 → 1024.

**Pan knobs — VPot relative encoding:**
- CC 16-23 in Logic's MCU mode = relative encoder messages, NOT absolute position.
  Sending absolute 0-127 caused "hyper sensitive in small range" (Logic read each value
  as a large CW rotation step).
- Fix: Potentiometer gains relative mode with delta accumulator. Sends sign-magnitude
  MCU VPot format: CW 0x01-0x3F, CCW 0x41-0x7F (bit 6 = direction, bits 0-5 = speed).
- ADC_PER_STEP = 8: 1023/8 ≈ 128 steps = full ±64 pan range coverage.
- First read silently captures position (no power-on parameter slam).
- Accumulator negated: physical CW → CW MIDI → pan right.
- invert removed from knob constructors (direction handled by accumulator negate).
