## Task 2: Hardware verification checkpoint (blocking)

Upload firmware and test against Logic Pro:

**Pickup mode (PICK-01 through PICK-06):**
1. Bank switch in Logic → physically move a fader → P button for that channel should start blinking
2. Sweep fader to DAW position → blink stops, snap pitch bend fires
3. Blink rate should be faster when far from target, slower as it approaches
4. Boundary edge case: both physical and DAW at 0 or 127 → immediate pickup, no blink

**Mode LEDs (LED-03):**
1. Toggle Loop/Cycle in Logic → K9 LED should follow
2. Toggle Punch In in Logic → K10 LED should follow
3. Toggle Metronome in Logic → K11 LED should follow
4. Compare observed note numbers against mcuConfig.h values:
   - MCU_NOTE_LOOP = 86
   - MCU_NOTE_PUNCH_IN = 85
   - MCU_NOTE_METRONOME = 89
5. If wrong, update mcuConfig.h with correct values
