<task type="auto">
  <name>Task 1: Fix FIX-01 — pointer dereference in handleControlChangeMessage</name>
  <files>src/inputManager.cpp</files>
  <action>
In `src/inputManager.cpp`, the `handleControlChangeMessage` method at line 25 contains:

```cpp
Button button = *(buttonRegistry.ccNumToButton[ccNum]);
button.setLedState(velocity == 127 ? HIGH : LOW);
```

This creates a temporary stack copy of the Button object. Calling `setLedState()` on the copy updates the copy's internal state but not the original object in the `gridButtons[]` or `trackButtons[]` arrays. The physical LED never changes.

Fix by using a pointer instead:

```cpp
void InputManager::handleControlChangeMessage(byte channel, byte ccNum, byte velocity)
{
    if (channel == 1)
    {
        if ((ccNum >= 102 && ccNum <= 117) || (ccNum >= 20 && ccNum <= 27))
        {
            Button* button = buttonRegistry.ccNumToButton[ccNum];
            if (button != nullptr) {
                button->setLedState(velocity == 127 ? HIGH : LOW);
            }
        }
    }
}
```

The null check guards against a missing CC number in the registry (defensive; should not happen in practice).
  </action>
  <verify>Run `pio run` from the repo root. Confirm the build succeeds with no errors on `inputManager.cpp`.</verify>
  <done>Build passes. `src/inputManager.cpp` contains `Button* button = buttonRegistry.ccNumToButton[ccNum]` and `button->setLedState(...)`. No copy-by-value dereference remains.</done>
</task>
